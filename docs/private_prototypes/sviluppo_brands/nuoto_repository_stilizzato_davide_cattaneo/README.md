# Repository MVP – Scheda Nuoto Stilizzata

Questa cartella è una prima base per una piccola repository GitHub di esercizi.

## Contenuto

- `scheda-nuoto.md` → scheda in Markdown, adatta a GitHub o a un sistema contenuti.
- `scheda-nuoto.html` → pagina HTML autonoma, stampabile e riutilizzabile.
- `progetto-generale.md` → visione del progetto generale e relazione con i brand.
- `images/` → immagini stilizzate in bianco e nero su sfondo neutro.

## Scopo del MVP

Questa versione serve a:

1. conservare le immagini in un posto stabile;
2. testare una struttura semplice per GitHub;
3. creare una prima scheda per il nuoto;
4. verificare come integrare tutto in PosturaCorretta, Percorso Integrato o altri brand.

## Nota importante

Le immagini presenti sono **versioni stilizzate statiche**. Possono funzionare già bene per una repository di esercizi. In un secondo momento si potranno sostituire o affiancare con:

- GIF reali,
- spritesheet,
- piccoli video,
- collegamenti ai video YouTube di PosturaCorretta.

## Struttura consigliata nel tempo

```text
repository/
├── images/
├── scheda-nuoto.md
├── scheda-nuoto.html
├── progetto-generale.md
└── README.md
```

## Possibile evoluzione

- libreria esercizi condivisa;
- generatore di schede per diversi brand;
- collegamento con video e percorsi;
- esportazione HTML / PDF / Markdown / JSON.
