# Progetto generale

L'idea non è soltanto pubblicare una singola scheda di nuoto, ma creare un **servizio trasversale** per organizzare esercizi, fotografie, spiegazioni e schede.

## Livelli del progetto

### 1. Libreria condivisa
Una base comune di esercizi con:
- immagini;
- descrizioni;
- dosaggi indicativi;
- eventuali collegamenti video.

### 2. Schede tematiche
Raccolte di esercizi organizzate per obiettivo, disciplina o percorso.

Esempi:
- nuoto;
- postura;
- mobilità;
- recupero;
- respirazione;
- altri percorsi futuri.

### 3. Brand e percorsi
Le schede possono poi essere usate da:
- **PosturaCorretta**;
- **Percorso Integrato**;
- eventuali altri brand futuri.

## Principio chiave

Gli esercizi non dovrebbero dipendere da un solo brand. La **libreria esercizi** è il nucleo comune. I brand la usano per costruire corsi, programmi e percorsi.

## Scelta attuale

Per ora conviene partire da una struttura molto semplice:
- file Markdown;
- file HTML;
- immagini in una cartella dedicata;
- repository GitHub come primo contenitore.

## Perché questa scelta

- le immagini sono già archiviate;
- il contenuto è leggibile e riusabile;
- non serve ancora un'applicazione complessa;
- il materiale può poi essere importato in una piattaforma più evoluta.

## Prossimi passi possibili

1. Validare la prima scheda di nuoto.
2. Decidere uno standard unico per i dati degli esercizi.
3. Collegare ogni esercizio a un video o a un timestamp YouTube.
4. Creare altre schede per altri percorsi.
5. Valutare in seguito un generatore di schede più automatizzato.
