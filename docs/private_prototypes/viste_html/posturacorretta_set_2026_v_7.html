Struttura del sistema

Materiale online, appuntamenti, ruoli, tirocinio e abilitazioni in un unico modello.

JSON incorporato · nessun backend
Schema 1

Percorso dello studente

flowchart TD A[Studente Base] --> B[Lezioni Base] B --> C[Studente Avanzato] C --> D[Lezioni Avanzate] D --> E{Vuole insegnare?} E -->|No| F[Continua come studente avanzato] E -->|Sì| G[Tirocinio Insegnante Base] G --> H{Valutazione Maestro} H -->|Idoneo| I[Insegnante Base] H -->|Da approfondire| G I --> J[Tirocinio Avanzato] J --> K{Valutazione Maestro} K -->|Idoneo| L[Insegnante Avanzato] K -->|Da approfondire| J L --> M[Possibile nomina a Maestro]
Schema 2

Gerarchia ruoli

flowchart LR S[Studente Base] --> SA[Studente Avanzato] SA --> IB[Insegnante Base] IB --> IA[Insegnante Avanzato] IA --> M[Maestro Insegnante] IB --> B1[Conduce Base] IA --> B2[Conduce Base + Avanzato] M --> B3[Conduce + Supervisiona + Abilita]
Schema 3

Struttura di una lezione

flowchart TD L[Lezione] --> B[Base] L --> A[Avanzata] B --> BA[Autonomia] B --> BG[Gruppo] B --> BI[Individuale] A --> AA[Autonomia] A --> AG[Gruppo] A --> AI[Individuale] BG --> T1[Tirocinante assistente / conduttore] BI --> T2[Tirocinante assistente / conduttore supervisionato] AG --> T3[Tirocinante assistente / conduttore] AI --> T4[Tirocinante assistente / conduttore supervisionato]
Schema 4

Tirocinio e abilitazione

flowchart TD A[Completa Avanzato] --> B[Richiede percorso insegnante] B --> C[Conduzione sul Maestro] C --> D[Compresenza gruppo · assistente] D --> E[Compresenza gruppo · conduttore] E --> F[Compresenza individuale su studente] F --> G[Conduzione supervisionata su studente] G --> H{Valutazione Maestro} H -->|Idoneo| I[Abilitazione al modulo] H -->|Non ancora| J[Altra esperienza supervisionata] J --> H
Schema 5

Oggetti minimi del futuro backend

flowchart LR C[Course] --> M[Module] M --> L[Lesson] L --> LL[LessonLevel\nbase / advanced] LL --> S[Session\ngroup / individual] S --> P[Participation] P --> U[User] U --> R[Role / Authorization] P --> T[Ticket / Experience] R --> A[Authorization per modulo]

Principio MVP

        
Una struttura, poche viste

        

          
Materiale online
Corsi → moduli → lezioni → Base / Avanzata.

          
Attività reale
Le stesse lezioni diventano appuntamenti di gruppo o individuali.

          
Formazione insegnanti
Compartecipazione alle sessioni reali, non corso separato.

          
Abilitazione
Il Maestro valuta e abilita per singolo modulo.
