Il file `home_old_backup.yml` conserva la precedente home costruita tramite componenti YAML. Contiene, tra le altre cose:

- l’hero «Cambiare punto di vista fa la differenza»;
- i tre interrogativi iniziali;
- gli ingressi verso programma, Percorso Integrato ed eventi;
- le risorse aggiuntive;
- la presentazione dei percorsi integrati per utenti e professionisti.

Questa versione rimane disponibile come fonte storica dalla quale recuperare testi, sezioni o impostazioni utili durante la revisione della nuova home.

## Regola di conservazione

`home_old_backup.yml` è un archivio e non deve essere modificato per aggiornare il sito. Le modifiche alla home attiva devono essere effettuate nelle fonti correnti.

Se in futuro servirà recuperare una parte della vecchia home, copiarla prima nella fonte attiva e adattarla alla gerarchia corrente:

- PosturaCorretta come brand educativo principale;
- Percorso Integrato come sottobrand operativo di PosturaCorretta;
- Il Giardino del Corpo come progetto collegato dedicato a filosofia ed esperienze.
