# Professionisti Corpo e Coscienza

Ogni professionista approvato avrà un file Markdown e una voce in `index.yml`.

Esempio:

```yaml
- slug: nome-cognome
  name: Nome Cognome
  city: Città
  latitude: 45.5416
  longitude: 10.2161
  public: true
  verified: true
  source: nome-cognome.md
```

Il profilo viene pubblicato soltanto dopo la verifica della formazione e dell'autorizzazione a mostrare i dati.
Le coordinate rappresentano la località da mostrare sulla mappa, non necessariamente l'indirizzo preciso dello studio.
