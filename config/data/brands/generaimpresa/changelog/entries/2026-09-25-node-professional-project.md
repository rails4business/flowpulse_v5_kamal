# Node professionali e progetti sono distinti dai domini

GeneraImpresa distingue ora due nature essenziali dei Node:

- **professional**, per un'attività o identità professionale;
- **project**, per un progetto, processo o contenitore organizzativo.

La presenza di un dominio è una caratteristica separata: un Node con almeno un dominio è anche un Brand. Un professionista o un progetto possono quindi essere preparati prima della pubblicazione del loro sito, senza cambiare identità quando il dominio viene attivato.

Radioestesia e Benessere è il primo caso inserito come Node `professional` ancora privo di dominio, temporaneamente raccolto da GeneraImpresa sotto **Brand in costruzione**. L'associazione alla professionista verrà completata quando sarà disponibile il relativo account.
