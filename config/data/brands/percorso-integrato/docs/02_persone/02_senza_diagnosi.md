# Posso iniziare senza una diagnosi?

Sì. I contenuti educativi, le attività di prevenzione e gli strumenti di orientamento possono aiutarti a conoscere meglio il corpo e a preparare le domande utili.

Non sostituiscono valutazioni, diagnosi, trattamenti o il parere di un professionista sanitario. Se sono presenti sintomi importanti, un trauma, un peggioramento o dubbi clinici, è opportuno rivolgersi al professionista adatto.
